## 🚀 Quick Start

### Step 1: Replace Images
1. Add your restaurant logo as `logo.png` (recommended: 300x300px)
2. Add gallery images as `portfolio1.jpg`, `portfolio2.jpg`, `portfolio3.jpg`

### Step 2: Enable GitHub Pages
1. Go to repository Settings
2. Scroll to "Pages" section
3. Select "main" branch as source
4. Your site will be live at: `https://yourusername.github.io/delhi-foods-website/`

### Step 3: Add Custom Domain
1. Purchase domain from GoDaddy, Namecheap, or similar
2. Update domain DNS settings to point to GitHub Pages
3. Add domain in GitHub Pages settings

## 🎨 Customization

### Change Colors
Edit the CSS variables in `style.css`:
```css
:root {
    --primary-color: #d32f2f;      /* Red */
    --secondary-color: #fdd835;    /* Yellow */
    --text-color: #333;
    --white: #ffffff;
}
```

## 🐛 Troubleshooting

**Images not showing?**
- Ensure image filenames match exactly: `logo.png`, `portfolio1.jpg`, etc.
- Images should be in the root directory

**Website not loading?**
- Wait 2-3 minutes after enabling GitHub Pages
- Check repository is public
- Clear browser cache

**WhatsApp button not working?**
- Update phone number in `index.html`
- Ensure phone number starts with country code
